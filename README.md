## What This Collection Does

Drop Shadows is a small set of scripts focused on exporting drop shadow properties from a selected Figma layer and converting those values into an After Effects script. It provides a practical handoff between design and motion work, reducing the need to recreate shadow settings manually.

The collection is intended for designers, motion artists, and people building repeatable workflows across Figma and After Effects. Its scope centers on export behavior, generated scripts, and the supporting files used to keep the transfer process organized and reusable.

## Script Areas

- Helpers for selecting layers in Figma
- Exporting drop shadow properties
- Creating scripts for After Effects
- Utilities for moving design data into motion workflows
- Helpers for arranging export data and formatting
- Example files showing possible usage
- Workspace and configuration notes
- Setup instructions and workflow documentation

## Getting Started

1. Download or clone the repository:
   ```bash
   git clone https://github.com/danielwbqking2623/drop-shadows-figma-script.git
   cd REPO
   ```

2. Inspect the project directory, including the available scripts and examples.

3. In Figma, choose a layer containing drop shadow values and start the export process supplied by the collection.

4. Take the resulting After Effects script into your motion workflow. Store reusable supporting files in the appropriate project directories.

A typical project arrangement includes:

- `scripts/` - core export and script-generation logic
- `examples/` - sample inputs and output references
- `configs/` - local configuration values
- `docs/` - process notes and usage documentation
